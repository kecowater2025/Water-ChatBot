# 유역별 심의요청서 작성예시 PDF

챗봇의 `유역별 작성예시` 메뉴는 아래 PDF 파일을 미리보기로 표시합니다.

- `han-river-review-example.pdf` - (한강) 부합성 심의요청서 예시.pdf
- `geum-river-review-example.pdf` - (금강) 부합성 심의요청서 예시.pdf
- `nakdong-river-review-example.pdf` - (낙동강) 부합성 심의요청서 예시.pdf
- `yeongsan-seomjin-river-review-example.pdf` - (영섬강) 부합성 심의요청서 예시.pdf

이 파일들은 Next.js `public` 폴더에 위치하므로 배포 후 다음 URL로 접근됩니다.

- `/examples/request-examples/han-river-review-example.pdf`
- `/examples/request-examples/geum-river-review-example.pdf`
- `/examples/request-examples/nakdong-river-review-example.pdf`
- `/examples/request-examples/yeongsan-seomjin-river-review-example.pdf`
